# AEVUM CORE — PUBLIC DEMO

**The Living Memory Space**  
**È un luogo. Non una app.**

*A Sea Eris Project*

Repository pubblico usato esclusivamente per testare Aevum Core su iPhone e Safari. Il progetto principale e la cronologia di sviluppo restano nel repository privato `AR-Night/aevum-core`.

## Genesis Demo 0.4

La demo include:

- universo orbitale animato;
- creazione, modifica ed eliminazione delle tracce;
- ricordi, sfide, sogni, paure, persone e obiettivi;
- archivio con filtri;
- focus sui nodi;
- importazione ed esportazione JSON;
- salvataggio locale nel browser;
- interazioni touch ottimizzate per iPhone;
- Preview iPhone HTML/CSS inclusa.

## File

- `index.html` — applicazione completa e interattiva;
- `iphone-preview.html` — preview statica senza JavaScript.

## Privacy

La pagina è pubblica, ma le tracce create non vengono salvate nel repository e non vengono inviate a server. Restano nel `localStorage` del browser usato. Non inserire comunque dati sensibili nella build demo.
