# AEVUM CORE — PUBLIC DEMO

**The Living Memory Space**  
**È un luogo. Non una app.**

*A Sea Eris Project*

Repository pubblico usato esclusivamente per testare Aevum Core su Safari e iPhone. Il progetto completo, la documentazione interna e la cronologia di sviluppo restano nel repository privato `AR-Night/aevum-core`.

## Genesis Demo 0.5 — Connections

La demo include:

- universo orbitale animato;
- ricerca di parole, persone e tag;
- animazione dei risultati diretti e dei nodi collegati;
- connessioni manuali tra tracce;
- data visibile sotto ogni nodo;
- eventi Piccoli, Medi e Grandi;
- archivio con filtri e ordinamento;
- importazione ed esportazione JSON;
- salvataggio locale nel browser;
- interazioni touch ottimizzate per iPhone;
- Preview iPhone HTML/CSS-only.

## Prova guidata

1. Apri la demo.
2. Premi **Vivi la storia demo**.
3. Cerca `Enea`.
4. Osserva le tracce dirette e quelle risvegliate dalle connessioni.
5. Tocca un nodo per aprirne la scheda.

## Privacy

La pagina è pubblica, ma le tracce create non vengono salvate nel repository e non vengono inviate a server. Restano nel `localStorage` del browser usato.

Non inserire dati personali, sanitari, aziendali o riservati nella build demo.
